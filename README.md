# 📝 Keep Notes App

A minimal, modern note-taking web app inspired by Google Keep. Built with **React 18** and **Material UI v5**, this app lets you create and delete quick notes easily with a beautiful, clean UI.

---

## ✨ Features

- 🖋 Add and delete notes instantly
- 🧼 Clean Material UI interface
- ⚡ Built using React Hooks (`useState`)
- 💅 Responsive layout with floating action buttons

---

## 🚀 Tech Stack

- [React 18](https://react.dev/)
- [Material UI v5](https://mui.com/)
- [Emotion CSS-in-JS](https://emotion.sh/docs/introduction)
- [UUID](https://www.npmjs.com/package/uuid)
